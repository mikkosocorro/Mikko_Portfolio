# Mikko Socorro Portfolio

Next.js (App Router), TypeScript, Tailwind CSS, Lucide React.

## Run

    npm install
    npm run dev

Open http://localhost:3000

## Build

    npm run build
    npm start

## Edit your content

- data/projects.ts : portfolio cards and filter categories
- data/gallery.ts : gallery images and categories
- app/about/page.tsx : bio, social links (replace the placeholder URLs and email)
- public/images : replace any SVG with your own photo (keep the file name, or update the path in data files)
